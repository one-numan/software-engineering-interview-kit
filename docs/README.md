## Core Philosophy

- **Depth over Trivia**: We favor questions that evaluate conceptual clarity, internal mechanics, and real-world system behavior over superficial syntax quizzing.
- **Runnable, Tested Code**: Every code snippet should be idiomatic, concise, and production-tested.
- **Transparent Progress**: We track exact question numbers honestly. A topic shows `0/200` until high-quality questions are verified and merged.
