## Candidate Evaluation Matrix

Use this scoring rubric when conducting or practicing mock interview sessions:

| Score | Rating | Definition |
|---|---|---|
| **1 / 5** | **No Hire** | Unable to explain basic concepts; code fails basic test cases; cannot identify algorithmic complexity. |
| **2 / 5** | **Leaning No Hire** | Struggles with runtime internals; requires substantial hints; code has unhandled edge cases. |
| **3 / 5** | **Borderline** | Explains standard concepts; solves problems with working code; lacks depth in concurrency or scaling. |
| **4 / 5** | **Hire** | Deep technical fluency; writes clean, idiomatic Python/SQL; proactively discusses edge cases and trade-offs. |
| **5 / 5** | **Strong Hire** | Exceptional mastery; discusses OS system calls, memory layouts, and distributed failure modes effortlessly. |
